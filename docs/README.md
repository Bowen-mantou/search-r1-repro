- 公式采用 Unicode 上下标：πᶿ = π_θ（当前策略，θ 为下标）、π₀ = 旧策略、
  πᵣ = 参考策略、Aᵢ = 第 i 条轨迹优势、μ/σ = 组均值/标准差、Σₜ = 对 token 求和；
